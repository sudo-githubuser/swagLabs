## 📌 About the Project
Welcome to **Swag Labs Automation**! This project is a robust automation framework designed to test the [Swag Labs](https://www.saucedemo.com/) demo website. It uses **Selenium WebDriver**, **TestNG**, and **Cucumber** to ensure seamless end-to-end testing of the application. This can be used as a boilerplate code for any **Cucumber-BDD** framework automation project.

## 🚀 Getting Started
### Prerequisites
Ensure you have the following installed:
- Java (JDK 11+)
- Maven
- ChromeDriver (latest version)

## ✨ Features
- **End-to-End Testing**: Comprehensive test coverage for the Swag Labs demo website.
- **Behavior-Driven Development (BDD)**: Uses **Cucumber** for writing test cases in plain English.
- **Parallel Execution**: Supports parallel test execution using **TestNG**.
- **Extent Reports**: Generates detailed and visually appealing test reports.
- **Page Object Model (POM)**: Ensures maintainable and scalable test automation.


## 🛠️ Tech Stack
- **Language:** Java ☕
- **Selenium WebDriver**: For browser automation.
- **TestNG**: For test execution and parallel testing.
- **Cucumber**: For BDD-style test cases.
- **Maven**: For dependency management.
- **Extent Reports**: For generating test reports.
- **Page Object Model (POM)**: For maintainable test automation.


### Installation
```sh
git clone https://github.com/sudo-githubuser/swagLabs.git
cd swagLabs
mvn clean install
```

### Running Tests
To run tests, execute:
```sh
mvn test
```
